这是什么

学习计划是一份按依赖关系排序的阅读路线，主线是一门研究生课程 （Optimization for Machine Learning and LLMs）， 辅以论文、开源代码与工业界研究博客。每条材料都标注「在哪、学什么、对应综述哪几节」，并在关键节点插入自测检查点。

覆盖范围：优化器谱系（SGD → 动量 → AdaGrad → RMSProp → Adam → AdamW）、 学习率调度与有效学习率、μP 与超参迁移、矩阵优化器与几何（Muon / Shampoo / Hyperball / Newton–Muon）、 Scaling Law 理论、强化学习（PPO / GRPO 到 MaxRL），以及一条深度学习理论支线。

页面可直接用浏览器打开，无需服务器。内容与本仓库的 Markdown 源文件同步。
