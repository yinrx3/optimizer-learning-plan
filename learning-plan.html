⛳ 检查点 1｜为什么神经网络训练不是经典优化问题

核心洞察 ①：两个"不干净" 你课上学过的优化（凸、确定性、低维）在深度学习里三个前提全被破坏：

前提 经典优化 神经网络训练
梯度可得 精确梯度 随机梯度（mini-batch），无偏但有方差
凸性 凸/强凸 → 全局最优 高度非凸，且维度 10^8\sim10^{12}
规模 小规模、可算 Hessian 巨大，二阶信息不可直接使用

后面 85 行里的所有优化器，都是在处理这三处破坏的后果。

核心洞察 ②：方差不是"噪声"，是"约束" 随机梯度的方差直接决定了步长的上限：方差越大，步长必须越小，否则更新被噪声主导。 反过来，减小方差的有效手段（增大 batch、动量平滑）都能允许更大步长——这就是"动量≈更大 batch"这个说法的实质。

核心洞察 ③：目标函数不同 我们在训练集上最小化，真正关心的是泛化。所以"训练损失降到多少"不是目的。 这门课后面所有的收敛性分析，都是在优化目标上做的——而优化好不等于泛化好（第 25 行 Wilson 那篇主题）。

⛳ 检查点 2｜动量到底在做什么

核心洞察 ①：动量 = 方差缩减，不是"加速" 梯度 EMA \bar g^t=(1-\beta)\sum_{\tau=1}^{t}\beta^{t-\tau}g^\tau 用的是过去很多步的梯度，因此相当于一个大得多的 batch 的估计。前提是相邻几步的参数点足够近（步长不能太大），否则"平滑"的其实是不同位置的梯度，反而引入偏差。

核心洞察 ②：有效 batch size 的换算 若 \beta=0.9，EMA 的有效窗口约 1/(1-\beta)=10 步。所以在 batch size B 下用动量，效果上接近用 10B 的 batch——但显存开销不变。这就是课程说"B 可以显著小于 mini-batch SGD 的 B"的含义。

核心洞察 ③：动量还能改善条件数 在二次型上做谱分析可以看到：动量对不同曲率方向的收敛速度影响不同，能抑制"峡谷"方向的震荡。所以动量同时缓解两个问题——梯度噪声与病态条件数。经典结论是后者（Nesterov 加速）在凸优化里更本质；而在深度学习里前者往往更实际。

⛳ 检查点 3｜自适应方法的本质

核心洞察 ①：自适应 = 按自己的历史量级归一化 自适应方法做的事只有一件：用每个坐标自己的梯度历史，把它归一化到同一起跑线。大梯度的坐标走慢，小梯度的坐标走快。 动机很直白：神经网络里不同参数的梯度量级能差几个数量级，共用一个步长时，小的几乎不动、大的来回震荡。

核心洞察 ②：AdaGrad 的累积项是个"特性"，也是"缺陷" \sqrt{v^t}=\sqrt{\textstyle\sum_{s\le t}g^s\odot g^s} 分母单调递增 → 步长单调递减到零。这对稀疏梯度是优点（稀有的特征被保留学习能力），对稠密持续的训练是缺点（训练还没完，步长就没了）。

核心洞察 ③：RMSProp 用 EMA 换取"不衰减" 把累加换成 EMA：v^t=\beta v^{t-1}+(1-\beta)g^t\odot g^t。步长不再必然衰减到零，但丢掉了长期记忆——很久以前的大梯度不再有影响。这是一次典型的"记忆长度"权衡。

⛳ 检查点 4｜Adam 的真正来历（理解 Adam 的钥匙）

核心洞察 ①：一句话说清 Adam 从 sign-SGD 出发： w^{t+1}=w^t-\eta\,\frac{g^t}{\sqrt{g^t\odot g^t}} 把分子换成梯度的一阶 EMA m_t、分母换成梯度平方的二阶 EMA v_t，就得到了 Adam。

所以 Adam 不是"动量 + RMSProp 拼起来"，而是 sign-SGD 的双 EMA 推广。 这个视角比"两个方法合并"清楚得多——它解释了为什么分子分母必须同时平滑。

核心洞察 ②：为什么"必须"平滑分母 sign-SGD 的 g/\sqrt{g\odot g} 只保留了符号，丢掉了幅度信息，太极端：梯度量级大的坐标本应走得稍快，现在被压成一样。 RMSProp 的做法是用 EMA 平滑分母，让"相对量级"信息保留下来，同时不因单步噪声而剧烈跳动。所以分母的平滑不是为了好看，而是为了在保留方向信息与抑制噪声之间取平衡。

核心洞察 ③：偏差修正是"初始化"的补丁 m^0=v^0=0 导致前几步的 EMA 被系统性低估（\mathbb{E}[m^t]=(1-\beta_1^t)g）。除以 1-\beta_1^t 正是把这个因子除掉。 注意：t 越大这个修正越接近 1，所以它只影响训练最初几百步——但没有它，warmup 阶段会被严重扭曲。

⛳ 检查点 5｜面试高频：Adam + L2 与 AdamW 的区别

核心洞察 ①：L2 正则为什么在 Adam 里"坏掉" 在 Adam 里加 L2 正则，\lambda w^t 会进入梯度 g^t，于是它被 \sqrt{\hat v^t} 除了一次——而不同参数的 \sqrt{\hat v} 量级差很多。结果等于给每个参数一个不同的、还随训练状态变化的衰减强度，这显然不是你想要的正则化。

核心洞察 ②：解耦是怎么做的 AdamW 把衰减挪到更新式的最后一项： w^{t+1}=w^t-\eta_t\frac{\hat m^t}{\sqrt{\hat v^t}+\epsilon}-\eta_t\lambda w^t 这样它各向同性地作用于参数，与自适应缩放彻底解耦。注意衰减项也乘了 \eta_t，所以学习率调度会同时缩放"梯度项"与"衰减项"。

核心洞察 ③：这一条为什么重要 它是"工程细节里藏着数学错误"的典型：Adam 的论文原版就是这么写的，而且被广泛实现了很多年，直到有人认真对照才纠正。 更重要的后果在第 42-44 行：一旦权重衰减正确解耦，它就直接决定了"权重范数平衡点"，进而决定有效学习率——这正是 Hyperball 那条线的起点。

⛳ 检查点 6｜一个真实存在的矛盾

核心洞察 ①：矛盾本身 默认超参（\beta_1=0.9,\beta_2=0.999）下，Adam 可能不收敛——Reddi 等人的定理给出了具体的随机凸问题反例，条件恰好是 \beta_1\le\sqrt{\beta_2}。 可是它遍地都在用、效果还很好。这个矛盾比定理更值得想。

核心洞察 ②：怎么理解这个矛盾 三句话可以把矛盾化解掉：

  1. "不收敛"说的是最坏情况，而实践关心的从来不是最坏情况；
  2. 反例是精心构造出来的，真实损失面不长那样；
  3. 深度学习里我们本来也不追求精确收敛（非凸、有噪声、还早停），能在有限步内把损失降下来就行。

所以正确的态度是：定理告诉你"算法在哪里会坏"，而不是"这个算法不能用"。

核心洞察 ③：读优化理论的通用分辨力 遇到任何"某算法不收敛/有反例"的结论，先问三个问题： ① 反例依赖什么条件？这些条件在真实训练里成立吗？ ② "收敛"的定义是什么？（凸？非凸？到稳定点？） ③ 结论是关于最坏情况还是平均/典型情况？ 这个分辨力在读完 Wilson 那篇（自适应方法泛化不一定更好）时同样要用。

⛳ 检查点 7｜一条可迁移的方法论

核心洞察 ①：一条可迁移的方法论 分析离散算法时，先把它写成连续时间的 ODE，分析 ODE 的稳定性与收敛，再映射回离散。 这套"离散 → 连续 → 回来"的套路你会反复见到：课程 §4.1 的 Adam 收敛、第 69 行 Peyré 的 Muon 梯度流、第 42 行的球面动力学，用的都是同一招。它比"Adam 收敛"这一个结论重要得多。

核心洞察 ②：为什么这么做有效 离散迭代的严格分析很难（步长、噪声、非线性耦合在一起）。但取步长很小的极限，迭代就"抹平"成一条连续轨迹，可以动用动力系统的整套工具：平衡点、稳定性、Lyapunov 函数、收敛速率。 代价是引入逼近误差，所以论文还得证明"插值过程弱收敛到 ODE 解"——这一步是整篇的技术核心。

核心洞察 ③：弱收敛与 Łojasiewicz

  • Łojasiewicz 不等式：非凸分析里的"准凸性"条件，用它可以把"收敛"升级为带速率的收敛。这是非凸优化里少数能给出速率的工具之一。

⛳ 检查点 8｜噪声有多大，才谈得上"加速"

核心洞察 ①：换一个更真实的噪声假设 前面所有收敛分析（含第 29 行的 Adam ODE）大多假设有界方差：\mathbb{E}\lVert g-\nabla f\rVert^2\le\sigma^2，一个与位置无关的常数。 Chen–Na–Kolar 换成了增长条件： \mathbb{E}\lVert g-\nabla f(x)\rVert^2\;\le\;M\lVert\nabla f(x)\rVert^2+\sigma^2 即方差 = 随真实梯度增长的乘性部分 + 常数加性部分。 这更贴近实际：在远离最优点的地方梯度大、噪声也大；接近最优点时噪声才降下来。

核心洞察 ②：结论——加速不是免费的 论文统一分析了四种加速方法（NAM / RMM / DAM+ / iDAM+），结论有层次： | 方法 | 乘性噪声小时 | 乘性噪声大时 | |---|---|---| | NAM（Nesterov 加速）、RMM、iDAM+ | ✅ 有加速 | ❌ 加速消失 | | DAM+（加速对偶平均） | ✅ | ✅ 仍有加速 |

也就是说："加速方法比 SGD 快"这个结论，依赖于噪声有多"乘性"。 噪声结构一变，某些加速方法就退化了——而 DAM+ 更稳健。

核心洞察 ③：从"收敛到点"到"收敛到邻域" 在常数步长 + 持续噪声下，算法不可能收敛到最优点本身，只能收敛到它的一个邻域（噪声地板）。这就是为什么论文讨论的是"以加速速率收敛到最优点的邻域"。 论文进一步提出 tail-averaged（尾部平均） 方案，让 DAM+ 与 iDAM+ 逼近理论下界（差一个对数因子）。 这个"邻域 + 尾部平均"的思路，和第 11 检查点里"EMA 梯度≈更大 batch"是同一类技法：用平均换方差。

⛳ 检查点 10｜本计划最关键的一问

核心洞察 决定训练进展的真实物理量是有效学习率 \eta_t^\star=\eta_t\,\frac{\lVert U_t\rVert }{\lVert W_t\rVert }\approx\text{角更新幅度（AUS）} 而权重范数 $\lVert W_t\rVert $ 在训练中持续增长，在名义调度之上自动叠加了一层衰减。

必须能回答的一问

"如果有效学习率才是真正决定训练进展的物理量，那么平时说'调 lr'，到底在调什么？"

核心洞察 ①：两个学习率 | 量 | 谁在控制 | 作用 | |---|---|---| | 名义 \eta_t | 你显式设定的调度 | 只是间接手段 | | 有效 \eta_t^\star=\eta_t\frac{\lVert U_t\rVert }{\lVert W_t\rVert } | 由权重范数自动调制 | 真正推进训练的量 |

因为 $\lVert W_t\rVert $ 在训练中持续增长，比值 $\lVert U_t\rVert /\lVert W_t\rVert $ 在下降 → 在名义调度之上自动叠加了一层衰减。

核心洞察 ②：这解释了三个反常现象

  1. 为什么不同调度效果差不多：三条峰值相差 2.4 倍的名义调度，1000 步后角更新幅度曲线高度重合——权重范数的增长把差异吸收平滑了。
  2. 为什么"调 lr"常常没什么用：你调的是名义量，而真正起作用的是它乘上一个你控制不了的因子。
  3. 为什么 weight decay 会影响学习率：衰减决定了权重范数的平衡点，也就决定了这个因子（第 20-21 行埋的伏笔在这里合上）。

核心洞察 ③：还有一个"守恒量" 在 Hyperball 约束下 \Delta\phi_t\approx\eta_t，于是累积角位移 \sum_t\Delta\phi_t\approx\int_0^T\eta_t\,\mathrm{d}t 也就是学习率的时间积分 = 权重向量转过的总角度。实证发现：不同任务的累积学习率相近时，最终损失也接近——这给了跨训练预算对齐的一个几何基准。

核心洞察 ①：一句话 优化器 = 在最速下降里选一个范数。

范数 得到的算法
\ell_2 SGD
\ell_\infty sign-SGD

核心洞察 ②：正交化不是"设计"，是"推导出来的" 谱范数 \ell_2\to\ell_2 的值等于最大奇异值；它的对偶范数是核范数（奇异值之和）。最速下降的解因此带上 \lVert \nabla\ell\rVert _* 与 UV^\top。 所以那个看起来突兀的 UV^\top，是核范数对偶性的直接后果——不是谁"想到"要正交化。理解这一点，Muon 就从"玄学 trick"变成了"必然结果"。

核心洞察 ③：两条路汇合 课程给了两条独立推导：

  • 路径 A：换范数 → 谱范数 → Muon；
  • 路径 B：交叉熵 Hessian → Fisher 信息 → 对角近似 → Adam；→ Kronecker 分解 → Shampoo。

而 Muon 与 Shampoo 在 \beta=0 时完全相同。 意味着"换范数"与"近似二阶信息"不是两件事——通过仔细选择矩阵范数，可以部分恢复二阶信息。

⛳ 检查点 18｜训练不稳定性：从"玄学"到可观测

核心洞察 ①：一个被忽视的问题 前面 80 行都在讲"怎么设计更好的优化器"。但工业界真实训练里，最常见、最烧钱的失败是——训练中途崩溃（损失断崖式下跌），伴随监控面板上的 Gradient Spike。 而排查手段极其原始：盯着 grad_norm 曲线猜——是学习率不对？数据脏？还是工程问题？然后端到端跑实验验证。这种排查高度依赖专家直觉，周期以「周」计。

核心洞察 ②：GradLoc 做的事 把全局的梯度突刺定位到具体 token。技术上三个要点：

  • 二分搜索：适配分布式框架分层定位（Global → Micro-Batch → Rank → Token），复杂度从线性降到对数级。没有它，排查一个 step 要花数万个 step 的时间。
  • 贪心 DFS：优先追踪梯度范数最大的一侧，并在异常点附近回溯，一次定位出多个异常 token。
  • 自适应阈值：适应聚合规模的动态变化，避免漏检与误检。

结果是能给出确定性的诊断："崩溃根源是 Batch 中第 2 个序列的第 5 个 token，在第 32 层反向传播时数值异常。" 代价可控：异常 step 耗时增加 1–3 倍，但只在检测到突刺时触发（always-on but dormant），摊销到整个训练几乎可忽略。
