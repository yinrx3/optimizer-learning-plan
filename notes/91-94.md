## ⛳ 检查点 19｜全表终测

1. **范数 → 几何 → 优化器**：选范数 = 选几何 = 选算法（第 46-50 行）
2. **Fisher 信息 → 二阶方法**：Adam（对角）、Shampoo（Kronecker）、Newton–Muon（牛顿型）、Newton Matching（函数空间）
3. **步子该迈多大**：$\eta_t\le 1/L$ → 调度形状 → 权重范数与有效学习率 → Hyperball 之争 → RL 里的 clipping

## ⛳ 检查点 20｜三个正交的设计轴：本表与综述的真正接口

1. 用一句话说清「范数轴」与「算子轴」各自回答什么问题。
2. 一个优化器的完整说明需要回答哪三个问题？
3. Muon 在三问中哪一问最强？Shampoo 呢？
4. 为什么说「范数轴有定理、算子轴没有定理」？这个差别对你使用它们有什么影响？
5. 用三问分析 MeZO 与 LoRA：它们各自只在哪一问上做了改动？这解释了它们的什么行为？
6. 综述说 Shampoo「捕捉的是梯度方差而非曲率」——请说明两把尺子为什么会给出不同分类。
7. **面试题**：如果让你设计一个新优化器，你会先动三问中的哪一问？为什么？
8. **面试题**：导师问你「综述里最值得做的是哪一个缺口」，你怎么答？（提示：说出「假设不成立」比「现象未理解」更有力）
9. **延伸（回到检查点 11）**：课程 §4.3 说「Muon 与 Shampoo 在 $\beta=0$ 时相同，所以两条路汇合」。用三轴语言重新表述这句话，并指出它在什么意义上是极限陈述。
10. **范数 → 几何 → 优化器**：换最速下降里的范数，依次得到 SGD（$\ell_2$）、sign-SGD（$\ell_\infty$）、Muon（谱范数）。第 46-48 行是这个链条的核心。
11. **Fisher 信息 → 二阶方法**：对角 Fisher 近似给出 Adam（第 50 行）；Kronecker 分解给出 Shampoo（第 50-52 行）；牛顿型重建给出 Newton–Muon（第 69 行）与 Newton Matching（第 90 行）。
12. **步子该迈多大**：从 $\eta_t\le 1/L$（第 6 行）→ 调度形状（第 31-37 行）→ 权重范数与有效学习率（第 42-44 行）→ Hyperball 之争（第 59-60 行）；RL 那边是同一个问题的另一种问法（clipping，第 76-82 行）。
13. **三个正交的设计轴**（检查点 20）：**信息从哪来**（FO / ZO）、**在哪个范数下最速下降**（$\ell_2$ / $\ell_\infty$ / 谱范数）、**参数被约束在什么集合上**（欧氏 / 球面 / 低秩 / Stiefel）。**任何优化器都是这三问的一组答案**；而综述自承的三个缺口，恰好都是两根轴拉扯的产物。
